# Develop History
## N-gram 统计语言模型 

单纯的词频统计，统计不可拆分的字符串出现次数  
缺点：不能理解词义
## Embedding 词嵌入向量 + FNN 前馈神经网络
### Embedding 词嵌入向量

高维度语义的映射  
含义相近的词在向量空间里的位置也相近  

### FNN 前馈神经网络
 
非线性映射与语义规律拟合  
缺点：单次只接收固定数量的token，且丢失早期的信息  
## RNN 循环神经网络

隐藏状态不断向后传递：通过一个记忆函数去记忆每一个信息  
时序记忆  
缺点：长期记忆能力弱，函数经过多次变换后会丢失信息  
## LSTM 门控制与长期传送带

遗忘门、输入门、输出门  
遗忘门：决定丢弃历史噪声  
输入门：决定保留当前新特征  
输出门：决定下一时刻输出  
缺点：
- 强制串行依赖，无法并行：只能一个 token 一个 token 进行计算，长文本效率低下
- 路径依赖：距离远的token要交换信息依旧需要经过中间的全部 token 

## Transformer

Attention Is All You Need  
每一个 token 直接查看全句里所有的 token，对于每一个 token 计算所有关联权重，得到新的向量，让孤立字面含义升维到动态语境含义（注入了上下文）， token 间的连接无距离衰减，不需要逐步传递  
### 1. 判断重要性
当前 token 评估其他 token 的关联度
### 2. 重点读取
按权重分配注意，聚合最有价值的信息

### 技术实现
|Q | K | V | 
|:---:|:---:|:---:|
| Query | Key | Value |  
| 查询 | 本身的属性 | 有意义的值 | 
| 当前 token 想找什么 | 每个 token 能被谁匹配 | 每个 token 实际贡献什么内容 |
> Q、K、V 都是输入经过线性变换学出来的，不是固定属性。
#### 1. Query 搜索关键词
首先生成概括 token 属性的 key ，例如“它”的 key 可以是代词，“绿色”的 key 可以是形容词、颜色属性、修饰候选等。  
按 token 进行 Query 查询，比对 Query 和 key 的值，匹配则值得关注，权重就高
#### 2. 怎么比对
多次训练  
Q 和 K 向量点积，值越大越匹配
#### 3. Softmax转换
将分数转换为权重
