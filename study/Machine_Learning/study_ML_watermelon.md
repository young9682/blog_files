# 西瓜书
## 1.2 基本术语
- 数据集：一组记录的集合。

- 示例/样本：数据集中每条记录是关于一个事件或对象的描述。

- 属性/特征：反映事件或对象在某方面表现或性质的事项。

- 属性值：属性的取值。

- 属性空间/样本空间/输入空间：属性张成的空间。

- 特征向量：一个示例在属性空间中的坐标向量。

- 维数：属性个数。

- 学习/训练：从数据中学得模型的过程，通过执行学习算法完成。

- 模型：学习算法在给定数据和参数空间上的实例化。

- 标记/标签：关于示例结果的信息。

- 样例：拥有标记信息的示例。

- 假设：模型对数据规律的猜测

- 真相：数据的某种潜在规律

- 分类：预测离散值；回归：预测连续值。

- 聚类：把样本分成若干组，每组叫簇，无标记。

- 监督学习：有标记；无监督学习：无标记。

- 泛化：模型适用于新样本

## 1.3 假设空间
- 归纳：由**特殊**到一般的*泛化*
- 演绎：由一般到**特殊**的*特化*

### 概念学习
从训练数据中归纳出某个目标概念，使模型能判断新对象**是否属于该概念**  

- 输出通常是布尔值：是 / 非，或 1 / 0。

- 更标准的说法叫：布尔概念学习。

- 训练数据由正例和反例组成：

    - 正例：属于目标概念

    - 反例：不属于目标概念

eg:  
> 如果目标概念是“狗”：

|图片	|真实类别	|概念学习标签	|模型判断|
|:---:|:---:|:---:|:---:|
|狗	|狗	|正例 / 1	|是狗|
|猫	|猫	|反例 / 0	|非狗|
|狼	|狼	|反例 / 0	|非狗|
|汽车|	汽车|	反例 / 0	|非狗|

## 1.4 归纳偏好
任何一个有效的机器学习算法必有其归纳偏好
