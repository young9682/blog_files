# 西瓜书第1章学习笔记：基本术语、假设空间与归纳偏好

> 本文整理周志华《机器学习》（西瓜书）第1章内容，主要记录基本术语、假设空间与归纳偏好。

## 1.2 基本术语

| 术语 | 含义 | 我的理解 |
|---|---|---|
| 数据集 | 一组记录的集合 | 类似一张表 |
| 示例/样本 | 关于一个事件或对象的描述 | 表中的一行 |
| 属性/特征 | 反映对象某方面性质的事项 | 表中的一列 |
| 属性值 | 属性的取值 | 某一列的具体值 |
| 属性空间/样本空间 | 属性张成的空间 | 所有可能样本所在的空间 |
| 特征向量 | 示例在属性空间中的坐标向量 | 用一个向量表示一个样本 |
| 维数 | 属性个数 | 特征数量 |
| 学习/训练 | 从数据中学得模型的过程 | 跑学习算法 |
| 模型 | 从数据中学得的结果 | 学到的规律 |
| 标记/标签 | 关于示例结果的信息 | 监督学习中的答案 |
| 样例 | 拥有标记信息的示例 | 样本 + 标签 |
| 分类 | 预测离散值 | 如猫/狗 |
| 回归 | 预测连续值 | 如房价 |
| 聚类 | 把样本分成若干簇，无标记 | 无监督学习 |
| 泛化 | 模型适用于新样本的能力 | 举一反三 |

### 易混点

- **示例 vs 样例**：示例不一定有标记，样例一定有标记。
- **属性空间 vs 特征向量**：属性空间是“空间”，特征向量是空间中的“坐标”。
- **分类 vs 回归**：分类输出离散值，回归输出连续值。

## 1.3 假设空间

- **归纳**：从特殊到一般，即泛化。
- **演绎**：从一般到特殊，即特化。
- **假设空间**：所有可能假设组成的空间。
- **版本空间**：与训练集一致的假设集合。

### 概念学习

概念学习是从训练数据中归纳出某个目标概念，使模型能判断新对象是否属于该概念。

- 输出通常是布尔值：是 / 非，或 1 / 0。
- 更标准的说法是：布尔概念学习。
- 训练数据由正例和反例组成：
  - 正例：属于目标概念。
  - 反例：不属于目标概念。

例如，目标概念是“狗”：

| 图片 | 真实类别 | 概念学习标签 | 模型判断 |
|---|---|---|---|
| 狗 | 狗 | 正例 / 1 | 是狗 |
| 猫 | 猫 | 反例 / 0 | 非狗 |
| 狼 | 狼 | 反例 / 0 | 非狗 |
| 汽车 | 汽车 | 反例 / 0 | 非狗 |

## 1.4 归纳偏好

- 归纳偏好：学习算法在假设空间中对某类假设的偏好。
- 任何一个有效的机器学习算法必有其归纳偏好。
- 如果没有偏好，所有假设等效，就无法产生确定模型。
- 常见原则：奥卡姆剃刀——若多个假设与观察一致，选最简单的那个。
- 没有免费午餐定理说明：没有普遍最优的算法，偏好要与问题匹配。

## 小结

这一节的核心是建立机器学习的基本语言：样本、特征、标记、模型、泛化、假设空间和归纳偏好。理解这些术语，后面看监督学习、无监督学习和模型评估会顺很多。
